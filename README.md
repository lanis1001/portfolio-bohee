## 프로젝트

### [DA-01] B2B 고객 추천 프로그램 설계
"기술 궁합 · 담당자 확인 · 업종 확인" 3가지 기준으로 점수를 매기는 프로그램을 만들어 서비스 핵심 기능으로 채택시키고, 약 1년간 계속 쓰이게 했다.
→ [자세히 보기](case-studies/da-01-lead-scoring-algorithm.md)

### [DA-02] TIPS 참가기업 데이터 분석
2018~2025년 TIPS 선정기업 4,004개 데이터를 검증·정제해 빠진 사업자번호의 78.8%를 채우고, 영업 후보 700개 이상을 실제 고객 목록에 반영시켰다.
→ [자세히 보기](case-studies/da-02-tips-data-analysis.md)

### [DA-04] 교육기관 데이터 자동 수집
사람이 손으로 찾던 교육기관 연락처를 자동 수집 프로그램으로 대신 모아 연락 가능한 고객 범위를 넓혔다.
→ [자세히 보기](case-studies/da-04-lead-sourcing-automation.md)

### [AI-01] AI에게 질문하는 방법 설계
영업 판단 기준을 AI 질문 설계에 반영해 기준 문서 12개로 정리하고, 고객 추천 프로그램의 업종 판단 로직에 적용했다.
→ [자세히 보기](case-studies/ai-01-prompt-engineering.md)

### [PM-01] AI 화면 기획 (보너스)
AI 추천 프로그램을 쓰는 화면을 10회 이상 고치며 기획했고, 대부분 실제 개발 · 출시로 이어졌다.
→ [자세히 보기](case-studies/pm-01-agent-screen-planning.md)

### [AI-02] 나만의 AI 업무 자동화 도구 (보너스)
Claude Agent SDK로 JD 분석 · 이력서 · 면접 준비 · 포트폴리오를 자동화하는 커스텀 스킬 8종을 직접 만들었다. 이 포트폴리오도 이 도구로 만들었다.
→ [자세히 보기](case-studies/ai-02-clio-automation.md)
