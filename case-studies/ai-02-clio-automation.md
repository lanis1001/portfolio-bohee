# [AI-02] 나만의 AI 업무 자동화 도구 (CLIO)

## 한 줄 요약
Claude Agent SDK로 JD 분석·이력서·면접 준비·포트폴리오 등을 자동화하는 커스텀 스킬 8종(CLIO)을 직접 설계·제작했다.

## 한눈에 보기
- **8종** 커스텀 스킬
- **100%** 단독 설계·제작

## 배경
JD 분석, 이력서, 면접 준비, 포트폴리오 정리를 지원마다 매번 새로 하는 게 비효율적이라고 느꼈다.

## 내 역할
AI 도구 설계와 제작을 혼자 했다.

## 방법론
Claude Agent SDK로 4가지 핵심 기능을 만들었다.

- **JD 분석**: 채용 공고 해독
- **이력서**: 자동 초안 작성
- **면접 준비**: 예상 질문·답변
- **포트폴리오**: 정리·시각화

## 결과
지금 이 포트폴리오도 이 도구로 만들었다. AI 도구로 직접 업무 자동화를 만들 수 있다는 걸 보여준 프로젝트다.

## 만든 파일
Claude Agent SDK 커스텀 스킬 8종

> 회사 업무가 아닌 개인 프로젝트라 비밀 정보 이슈가 없다.
